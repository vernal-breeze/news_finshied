## 📋 完整使用流程

### 1. 访问 AI 稿件页面
打开浏览器访问：http://localhost:3000/ai-article

### 2. 新建稿件
点击右上角的"新建稿件"按钮

### 3. 选择线索
- 在弹窗中勾选要整合的新闻线索
- 支持多选
- 选择后会自动显示已选数量

### 4. 自动填充
系统会自动填充以下内容：
- **标题**：单条线索用原标题，多条显示"多线索整合：X 条线索"
- **分类**：继承第一条线索的分类
- **内容**：整合所有线索的内容
- **关键词**：自动提取线索的关键词
- **摘要**：自动提取内容的前 200 字

### 5. 编辑（可选）
你可以修改任何自动填充的内容：
- 修改标题
- 调整分类
- 编辑内容
- 添加/删除关键词
- 完善摘要

### 6. 保存
点击"确定"按钮，系统会：
- 调用 AI API 生成内容（如果配置了 API Key）
- 自动保存到数据库
- 显示成功提示
- 刷新稿件列表

### 7. 查看结果
在"AI 生成稿件"标签页查看生成的稿件

## 🔧 技术细节

### 数据格式
保存到数据库的稿件包含：
```json
{
  "title": "稿件标题",
  "content": "稿件内容",
  "abstract": "内容摘要",
  "category": "新闻分类",
  "tags": ["标签 1", "标签 2"],  // 数组格式
  "status": "draft",
  "author": "AI 助手"
}
```

### API 调用
- 前端调用：`POST /api/articles`
- 状态码：200 表示成功
- 状态码：422 表示验证失败

### 错误处理
如果保存失败，会在浏览器控制台显示：
- 保存稿件数据
- 错误详情
- 后端返回的错误信息

## 🎯 功能特点

### 自动保存
- 选择线索后自动触发保存
- 无需手动点击确定
- 保存成功后自动关闭弹窗

### 多线索整合
- 支持选择多条线索
- 自动整合格式化内容
- 用分隔符区分不同线索

### 智能填充
- 自动提取关键词
- 自动生成摘要
- 自动设置分类

## 📊 测试验证

### 成功标志
- 浏览器显示"AI 稿件生成并保存成功"
- 后端日志显示：`POST /api/articles HTTP/1.1" 200 OK`
- 稿件列表中出现新生成的稿件

### 失败排查
如果保存失败：
1. 打开浏览器控制台（F12）
2. 查看 Console 中的错误信息
3. 检查后端日志
4. 确认数据格式正确

## 💡 使用建议

1. **选择线索**：选择 2-5 条相关线索效果最佳
2. **编辑内容**：AI 生成后建议人工审核和编辑
3. **关键词**：添加 3-5 个关键词便于检索
4. **分类**：根据内容选择合适的分类
